# Loan Eligibility Checker

## About the Project
This project checks whether a customer is eligible for a loan based on their employment type, monthly income, requested loan amount, existing monthly EMI, and credit score.

## Technologies Used
- JavaScript
- Node.js

## Features
- Takes customer details as input.
- Checks loan eligibility.
- Displays the eligibility result.

## How to Run
1. Install Node.js.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

   `node loans.js`

5. Follow the instructions displayed in the terminal.
